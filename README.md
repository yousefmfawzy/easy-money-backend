# Easy Money Backend

This is the backend for **Easy Money**, a simulated camp market application built for the Avamina Scouting Group. It facilitates trading ETFs denominated in the camp currency, لحوح. 

## Requirements

- Python 3.10+
- SQLite (included with Python)
- Docker (optional)

## Environment Configuration

Copy `.env.example` to `.env` and configure the variables.

```bash
cp .env.example .env
```

| Variable | Description |
|---|---|
| `DATABASE_URL` | SQLAlchemy connection string (e.g., `sqlite:///./data/easymoney.db`) |
| `ADMIN_USERNAME` | The username for the admin account (default: `admin`) |
| `ADMIN_PASSWORD` | The password for the admin account. **Must be changed.** |
| `JWT_SECRET` | Secret key for signing JWTs. Must be at least 32 characters. |
| `JWT_EXPIRE_MINUTES` | Access token lifespan in minutes (default: 720 / 12 hours) |
| `CORS_ORIGINS` | Comma-separated list of allowed origins (e.g., `http://localhost:5173`) |
| `UPLOAD_DIR` | Directory to store uploaded images (e.g., `./uploads`) |
| `MAX_UPLOAD_MB` | Maximum size for an uploaded image in megabytes (default: 5) |
| `CURRENCY` | The currency symbol used across the app (default: `لحوح`) |

## Installation & Startup

To run locally:

```bash
cd backend
python -m venv .venv
.venv/Scripts/activate          # Windows
# source .venv/bin/activate     # Linux/macOS
pip install -r requirements.txt
```

Run database migrations:

```bash
alembic upgrade head
```

Start the application:

```bash
uvicorn app.main:app --reload
```

## Initializing the Admin & Database

The backend automatically creates the `data` and `uploads` directories if they don't exist.
When the server starts, it runs a seed script that idempotently:
1. Creates the seven initial ETFs.
2. Initializes the single admin user with the credentials provided in your `.env`.

## Upload Directories

The `UPLOAD_DIR` (by default `./uploads`) is divided into subdirectories automatically created at startup:
- `etfs/` - Stores ETF logo uploads.
- `requests/` - Stores trade request image uploads.

Images are accessible at `/uploads/{path}` for read-only access (e.g. `/uploads/etfs/logo.jpg`).

## API Documentation

Swagger API documentation is automatically generated by FastAPI and is available at:
**[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)**

## Running Tests

To execute the test suite, ensure your `.env` is configured (or use a test-specific `.env`), then run:

```bash
pytest -q
```

## Docker

To run the application using Docker:

```bash
cd backend
docker build -t easy-money-backend .
docker run -p 8000:8000 --env-file .env \
  -v "$PWD/data:/app/data" -v "$PWD/uploads:/app/uploads" easy-money-backend
```

**Note:** Always mount the `data/` and `uploads/` directories as volumes to persist the SQLite database and uploaded images between container restarts.
